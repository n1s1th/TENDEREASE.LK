| Type     | Use For               |
| -------- | --------------------- |
| feat     | New feature           |
| fix      | Bug fix               |
| refactor | Code improvement      |
| docs     | Documentation changes |
| style    | Formatting only       |
| test     | Adding tests          |
| chore    | Config/setup work     |


eg: 
feat(tender): implement tender creation API
fix(vendor): prevent duplicate NIC registration
refactor(evaluation): optimize scoring logic

feat(vendor): add vendor registration form
fix(auth): handle JWT expiration properly
style(tender): adjust layout spacing
