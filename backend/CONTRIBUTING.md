# Contributing to TenderEase

Welcome to the TenderEase E-Procurement System project! We're glad you're here.

## Getting Started

1. Set up your local development environment following the instructions in `README.md`.
2. Find an issue to work on or propose a new feature.
3. Check out a branch (`feature/your-feature-name` or `bugfix/issue-description`).
4. Write clean, tested code that adheres to our style guide.

## Pull Request Process

1. Ensure all tests pass.
2. Update the README or documentation if your changes require it.
3. Submit a pull request to the `dev` branch.
4. Obtain approval from at least one reviewer.

## Coding Standards

- Use Java 21 features appropriately.
- Write tests for your changes.
- Ensure Swagger annotations are updated for any API changes.
- Follow standard Spring Boot project structure.
