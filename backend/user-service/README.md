# User Service

## Description
Manages users, roles, and profiles.

## Responsibilities
- User CRUD
- Profile Management
- Role Assignment

## API Endpoints
| Method | Endpoint | Description |
|--------|----------|-------------|
| POST   | /api/users | Create users |
| GET    | /api/users | List users |

## Dependencies
- Common Library
- Eureka Client
- PostgreSQL
- Keycloak
